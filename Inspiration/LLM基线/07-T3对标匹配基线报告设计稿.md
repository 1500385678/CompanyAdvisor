## 4. 方法与流程

### 4.1 两段式流程(规则聚类 + LLM 筛 Top-K + 解释)

**第一段:规则引擎预聚类**(沿用 03 prompt §4.1 规则聚类表)

```python
# 沿用 03 prompt §4.1 规则聚类表(契约式,Phase 0 手工对照,Phase 1 写 scripts/peer_match_engine.py)
def rule_pre_select(target, all_companies):
    """输入 target + 38 种子清单,输出 8-15 家候选"""
    candidates = []
    for c in all_companies:
        # 行业(申万二级)必须一致(硬约束)
        if c["industry_sw_l2"] != target["industry_sw_l2"]:
            continue
        # 主营关键词 Jaccard 相似度(软约束 ≥ 0.4 入选)
        sim = jaccard(target["main_business"], c["main_business"])
        if sim < 0.4:
            continue
        # 规模带:营收或市值在目标公司 0.3-3 倍
        if not (0.3 * target["fy_revenue_cny_yi"] <= c["fy_revenue_cny_yi"] <= 3 * target["fy_revenue_cny_yi"]
                or 0.3 * target["market_cap_cny_yi"] <= c["market_cap_cny_yi"] <= 3 * target["market_cap_cny_yi"]):
            continue
        # 加分项:申万三级一致 / 跨市场 / 护城河类型一致
        reasons = [f"同申万二级:{target['industry_sw_l2']}", f"主营相似:{sim:.2f}"]
        if c["industry_sw_l3"] == target.get("industry_sw_l3"):
            reasons.append("同申万三级(加分)")
        if c.get("moat_type") == target.get("moat_type_hint"):
            reasons.append("护城河类型一致(加分)")
        candidates.append({**c, "rule_pre_selected": True, "rule_reasons": reasons})
    return candidates[:15]  # 截断到 15 家上限
```

**第二段:LLM 筛 Top-K + 解释 + 对标表**(沿用 03 prompt §4.2)

```
输入:target JSON + candidate_pool(8-15 家,带 rule_reasons)+ max_matches + valuation_basis
输出:Top-K 5-10 家 + 多维对标表(营收/净利/毛利率/估值)+ 可比叙事 + target_positioning
约束:LLM 只能从 candidate_pool 选,不能新增候选(03 §4.2 显式约束)
```

### 4.4 盲评规则(防止自评偏差 + 跨市场可比性偏差)

- **5 目标公司 × 1 主模型** = 5 票飞书 P0 用户盲评(张勇 1 票 + 至少 4 位种子用户匿名)

- **评分维度**:**Top-K 命中率 + 矩阵完整度 + 可比叙事质量(3 维 4 档)**

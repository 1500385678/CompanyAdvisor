## 3. 关键设计点

### 3.1 复用 08-27 落地的 pdfplumber 抽取

```python
sys.path.insert(0, str(Path(__file__).resolve().parent))
from pdfplumber_demo import extract_pdf
```

不重新实现 PDF 解析层,直接复用已稳定的 JSON 契约 `{source, page_count, pages: [{page_no, text, tables: [{table_no, rows}]}]}`。

### 3.2 4 模型 provider 占位

| 模型 | provider | env_key | 成本 / 1K 估算 |
|------|----------|---------|---------------|
| claude-sonnet-4 | anthropic | ANTHROPIC_API_KEY | $0.015 |
| gpt-4o | openai | OPENAI_API_KEY | $0.010 |
| qwen-finance | dashscope | DASHSCOPE_API_KEY | $0.004 |
| ollama-qwen2.5-7b | ollama-local | (本地) | $0.000 |

**本骨架阶段 4 模型全 `stub=True`**,`call_llm()` 统一走 `call_llm_stub()`,返回 4 段占位 + `self_eval_score=1`(不可用档,标识 stub)。

### 3.3 jsonl 输出契约(每行 1 条)

```json
{
  "run_id": "uuid4",
  "task": "T1-财报速读",
  "model": "claude-sonnet-4",
  "sample_id": 1,
  "company": "贵州茅台",
  "ticker": "600519.SH",
  "period": "FY2020",
  "pdf_path": "samples/llm_eval/raw/600519.SH-2020.pdf",
  "extract_status": "ok-stub",
  "page_count": 0,
  "table_count": 0,
  "extract_seconds": 0.0,
  "prompt_version": "T1-v0.1",
  "llm_call_status": "ok-stub",
  "llm_output": {...},
  "self_eval_confidence": "low",
  "self_eval_score": 1,
  "latency_seconds": 0.0,
  "cost_usd": 0.0,
  "timestamp": "2026-09-04T03:30:00+08:00"
}
```

**真跑时**:`llm_call_status: "ok"`、`page_count` 与 `table_count` 来自真实 PDF 抽取、`self_eval_score` 由模型 confidence + 人工盲评共同给出、`latency_seconds` 与 `cost_usd` 由真实调用统计。

### 3.4 4 档评分占位(沿用 01 §4 校准表)

- 4 精确:数字 100% 命中 + evidence ≤ 60 字 + 语义无歧义
- 3 可接受:数字 100% 命中 + evidence > 60 字或语义略模糊
- 2 可改:数字错/漏 + evidence 错位 + 4 段结构对
- 1 不可用:结构错/字段缺失/编造

本骨架 `call_llm_stub()` 强制返回 `self_eval_score=1`,标识 stub 数据不可用;真跑时由模型自评 + 飞书 P0 用户盲评(05 §4.3)校准。

## 4. 边界(明确不做什么)

- **不实际跑 LLM provider**:4 模型调用全 stub,无 API 调用
- **不下载真实 25 份年报**:本骨架读 manifest 占位,真实 PDF 入 `samples/llm_eval/raw/` 后才接
- **不改 T1 prompt v0.1**:本骨架装载 v0.1 契约,prompt 优化点入 v0.2(09-06 跑批后)
- **不勾选 §5 #4 checkbox**:本骨架是 05 设计稿"骨架"补完,不等同"基线报告落地"
- **不绑死 1 个模型**:4 模型对比是基线报告核心价值,4 模型并列 stub,真跑时统一替换

1. **分配 token**:`export ANTHROPIC_API_KEY=...` / `OPENAI_API_KEY=...` / `DASHSCOPE_API_KEY=...` (ollama 本地无需)

## 4. 方法与流程

### 4.1 两段式流程(规则引擎 + LLM 注释)

**第一段:规则引擎预评分**(沿用 02 prompt §4.1 档位对照表)

```python
# 沿用 02 prompt §4.1 档位对照表(契约式,Phase 0 手工对照,Phase 1 写 scripts/moat_rule_engine.py)
def rule_pre_score(dimension, metrics_5y):
    """输入 5 年 metrics,输出 1-4 档"""
    if dimension == "D1":
        mean, sigma = metrics_5y["D1_gross_margin"]["mean"], metrics_5y["D1_gross_margin"]["sigma"]
        if mean >= 50 and sigma <= 3: return 4
        if 30 <= mean < 50 or sigma <= 5: return 3
        if 15 <= mean < 30 or 5 < sigma <= 8: return 2
        return 1
    # ... D2-D5 同结构(02 §4.1)
```

**第二段:LLM 注释 + 校核**(沿用 02 prompt §4.2 + §5 Pydantic)

```
输入:metrics + rule_pre_scores + raw_evidence_pool
输出:MoatLLMReport(5 维 dimensions + total + moat_type + narrative + limitations)
约束:llm_confirmed=true 时 llm_override_score 必须为 None(不轻易否决规则)
```

### 4.2 4 档评分(沿用 02 prompt §6,叠加总分一致性)

| 档位 | 含义 | 触发条件(5 维任一维 + 总分一致性) |
|------|------|----------------------------------|
| 4 完全可用 | 规则档位 + LLM 叙事 + 证据回链全部对齐,无 hallucination,总分与 5 维一致 | `llm_confirmed=true`;evidence 全部可在 pool 中定位;narrative 数字与 metrics 一致;`total` = 5 维求和(±2) |
| 3 基本可用 | 规则档位合理,LLM 叙事合理但 evidence 略泛化(quote 较长或跨段拼接),总分 ±5 内 | `llm_confirmed=true`;evidence 存在但允许轻微意译;数字一致;`total` 与 5 维求和差 ≤ 5 |
| 2 可参考 | 规则档位 1 处偏差 / LLM 主动下调 1 档 / evidence 池缺失 1 维 / 总分 ±10 | `llm_override_score` 非空且 ≤ rule_score;evidence 缺失维有 limitations 说明;`total` 偏差 ≤ 10 |
| 1 不可用 | LLM 幻觉 / 严重偏离护城河 schema / JSON 字段缺失 / 总分完全错乱 | 数字与 metrics 不符;evidence 在 pool 找不到;moat_type 与 total 不匹配(80+ 不是 deep) |

### 4.3 端到端跑批脚本(沿用 05.1 骨架,扩展 T2 适配)

- **入口**:`scripts/llm_eval_runner.py --task t2`(05.1 骨架已就位,需在 MODELS + 任务清单中加 `t2` 分支)
- **职责**:① 加载 25 组 metrics JSON + 规则档位 + 证据池 → ② 调 T2 prompt A(规则对照,无 LLM) → ③ 调 T2 prompt B(LLM 注释) → ④ 输出 25 × 4 = 100 条结果到 `samples/llm_eval/06-t2-results.jsonl`
- **复跑**:同输入下 4 模型各跑 1 次,温度 0,seed 固定 42
- **不在本期**:规则引擎代码化(本期 4.1 手工对照,Phase 1 写 `scripts/moat_rule_engine.py`)

### 4.4 盲评规则(防止自评偏差 + 规则自评偏差)

- **5 公司 × 1 主模型** = 5 票飞书 P0 用户盲评(张勇 1 票 + 至少 4 位种子用户匿名)
- **盲评材料**:给 LLM 输出 + 真实 metrics + 证据池原文(无 prompt / 无模型名 / 无规则档位 / 无自评档)
- **评分维度**:**5 维 D1-D5 各 4 档 + 总分一致性 4 档**(沿用 02 §6 校准表)
- **差异处理**:盲评 < 自评 1 档以上 **或** 盲评 < 规则 1 档以上 → 计入"三方偏差"统计,触发 prompt 复核 + 规则表复核

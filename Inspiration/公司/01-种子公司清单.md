# 01-种子公司清单(Phase 0 §5 第 2 项)

> **入库日期**:2026-08-26
> **对应主计划**:[项目开发计划.md](../../项目开发计划.md) §5 第 2 项
> **覆盖行业数**:8(消费 / 医药 / 互联网 / 新能源 / 半导体 / 金融 / 汽车 / 制造)
> **公司总数**:38 家(A 股 23 / 港股 7 / 美股 8,含 1 家未上市参考样本 DJI)
> **用途**:Phase 1 MVP 财报速读 + 对标矩阵 + 护城河评估的种子数据基础

---

## §1 选股原则

- **三市覆盖**:A 股(主板/创业板/科创板)· 港股(恒生综合)· 美股(中概/全球龙头),避免单一市场偏差
- **行业映射**:8 个行业,每个 4-6 家,便于 Phase 1 对标矩阵"行业聚类"训练
- **数据可得性**:优先年报/招股书 PDF 公开可下载(巨潮 / 港交所 / SEC EDGAR)
- **样本多样**:每行业覆盖 1-2 家行业绝对龙头 + 1-2 家细分赛道代表,补 1 家潜在"护城河样本"争议公司
